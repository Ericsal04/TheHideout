# TheHideout
### Project Description
TheHideout is a web application designed to help players of Valve's game Deadlock find teammates and form groups. The platform will allow users to create accounts, customize their profiles, and create or browse Looking for Group (LFG) posts based on preferences such as rank, region, and playstyle.

The goal of TheHideout is to provide players with a convenient way to find compatible teammates outside of the game's matchmaking system.

# Agile Planning
### Development Methodology

TheHideout will follow the Agile Scrum methodology. Development will be divided into one week sprints to allow us to implement features incrementally, track progress, and make adjustments throughout the semester.

Our team will GitHub Projects for task management. Each sprint will focus on completing a set of prioritized tasks from the product backlog.

### User Stories
As a new player, I want to register an account so that I can connect with other Deadlock players.

As a returning user, I want to log in so that I can access my account.

As a signed-in user, I want to log out so that I can keep my account secure on a shared device.

As a user, I want clear error messages when I submit invalid information so that I can correct it.

As a visitor, I want to understand how TheHideout works so that I can decide whether to join.

As a player, I want to list my preferred roles, skill level, and play style so that others can see whether we would be good teammates.

As a player, I want to find people with similar goals so that I can build a compatible squad.

As a player, I want to contact potential teammates so that we can arrange a match.
